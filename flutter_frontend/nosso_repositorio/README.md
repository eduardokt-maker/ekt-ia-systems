# Nosso repositório de marcas

Este diretório guarda cópias locais de marcas publicadas em sites oficiais das
companhias. `manifest.json` registra o ticker, o nome verificado, a página
oficial, a URL exata do arquivo e a data da coleta.

As imagens não devem ser substituídas por agregadores de mercado. Para atualizar
o catálogo, execute `python tools/atualizar_logos_oficiais.py` na raiz do projeto
e revise as entradas marcadas como erro antes de publicar.
